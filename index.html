5개 환경 요소를 같은 비중으로 계산해요

각 항목: 적정 100점 · 주의 60점 · 개선 필요 20점

종합 점수 = (온도 + 습도 + CO₂ + 조도 + 소음 점수) ÷ 5

80점 이상: 쾌적 / 60~79점: 주의 / 60점 미만: 개선 필요

경곗값은 해당 범위에 포함합니다. 주의 범위에서도 적정 범위가 우선합니다. 모든 수치와 점수는 이 프로젝트에서 정한 학습용 예시이며 공인 쾌적도 지수나 법적 판정 기준이 아닙니다. 계절·수업 활동·측정 위치에 맞춰 기준을 검토해 주세요.

입력 → 처리 → 출력 → 저장
